WAIS INVEST Website v1

品牌：
WAIS INVEST
Wisdom • Analysis • Intelligence • Strategy
Think Clearly. Invest Wisely.

打開方法：
1. 解壓縮 ZIP。
2. 雙擊 index.html。
3. 用 Chrome、Edge、Safari 或 Samsung Internet 開啟。

現有功能：
- Dashboard
- Market Risk Score
- Cash Recommendation
- Defense Mode
- Monday Action Plan
- Portfolio Manager
- Top Picks
- Hidden Gems
- Research Library
- Risk Engine
- Decision Journal
- Save Snapshot

資料儲存：
Portfolio、Risk Score 同 Journal 會保存在你目前瀏覽器的 localStorage。
清除瀏覽器資料可能會刪除它們，所以可定期按 Save Snapshot 備份。

重要：
現時未接駁即時股價或新聞 API。
股票狀態及評分屬網站示範／研究框架資料，不是即時投資建議。
